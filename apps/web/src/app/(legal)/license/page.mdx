# Licence

**Sendsprite is open source under the MIT License.** That covers all of it: the
server you can self-host, the `sendsprite` SDK and CLI, the `@sendsprite/mcp`
server and the shared code bundled into them. One licence, no exceptions, no
clauses that kick in later.

## What you can do

- **Self-host it** for yourself, your company or your customers, on any
  infrastructure, for free.
- **Modify it** and keep the changes to yourself. There is no copyleft: you
  never owe anyone your source.
- **Embed the SDK, CLI or MCP server** in a closed-source product. Installing
  them puts you under no obligation to publish anything.
- **Sell it.** Run Sendsprite as a paid service, ship it inside something you
  charge for, fork it into a competing product. The licence permits all of
  that.

The only condition is the one every MIT project has: keep the copyright and
permission notice with the code.

The MIT License covers copyright in the software and grants no right to use
those marks. Fork freely, but run a public service under your own name — the
[trademark policy](https://github.com/defy-works/sendsprite/blob/master/TRADEMARK.md)
sets out what needs no permission and what does.
